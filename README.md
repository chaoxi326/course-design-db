# 数据库与信息课程设计

## 项目简介
（超市进销存管理系统）

## 目录结构说明
- `数据库/` – 表结构、初始化SQL脚本
- `后端服务代码/` – 后端API代码
- `前端代码/` – 前端界面代码
- `log/` – 每日开发日志（Markdown格式）

## 部署说明
1. 数据库：运行 `数据库/init.sql` 创建表。
2. 后端：进入 `后端服务代码/`，执行 `npm install` 或 `pip install -r requirements.txt`，然后 `npm start`。
3. 前端：进入 `前端代码/`，用 Live Server 打开 `index.html`。

## 运行环境
- 操作系统：Windows / Mac / Linux
- 数据库：MySQL 8.0
- 后端：Node.js 18+ / Python 3.10
- 前端：现代浏览器
