## 遇到的问题与解决方案
- **问题 1（JDK 24 + Lombok 兼容）**：后端返回 JSON 字段名全变小写（`eid`、`ename`），前端传的 `eId` 后端收不到，登录永远返回"工号或密码错误"。
  - **解决**：在实体类字段上添加 `@JsonProperty("xxx")` 强制指定 JSON 序列化/反序列化字段名。
- **问题 2（BCrypt 哈希前缀不兼容）**：使用 Python 生成的 BCrypt 哈希前缀为 `$2b$`，Java Spring Security 只认 `$2a$`，导致登录验证失败。
  - **解决**：用 Java 的 `BCryptPasswordEncoder` 重新生成哈希，确保兼容。
- **问题 3（Maven 命令行不可用）**：本机无独立 Maven 安装，Node.js 版 `mvn` 包损坏。
  - **解决**：使用 IDEA 自带的 Maven 插件进行依赖管理和编译。
